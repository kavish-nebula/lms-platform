# Healthcare Automation vs AI derivative

`lesson.json` is the seven-section, source-mapped fictional clinic-administration
version of the standalone Module 1 Automation vs AI lesson. It illustrates
appointment requests, fixed rules, administrative exceptions, queue-history
patterns and staff review. The original production recording and transcript
remain separate and unchanged. Short source comparisons retain the teaching
needed by the existing checkpoint questions.

`audio/section-1.wav` through `section-7.wav` contain the matching Kokoro narration
and context bridges. The total measured playback duration is **406.95 seconds**
(6 minutes 47 seconds), excluding knowledge-check interaction. The manifest lists
each clip's checksum, duration and encoding. These are real, non-silent generated
clips, not mock test audio. Browser checks sampled unmuted playback, automatic
section advancement and switching to the unchanged original recording; all seven
clips passed range-delivery and signal checks. This is not a full human listening
or accessibility certification.

No learner profile, enrollment, private cache URL, database snapshot or credential
is included. This is a versioned content/audio artifact, not a learner record or
automatic publication/approval action. The runtime continues to validate source,
learner, release and voice fingerprints before serving an adapted revision; simply
copying a clip into a cache does not establish a valid learner-specific revision.
Use the app's normal adaptation workflow on another installation. These files may
serve as a trusted reference for exact matching scripts and Kokoro configuration;
never pair them with a different script, voice or learner-context revision.
