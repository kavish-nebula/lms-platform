# Module production reference

`ai-essentials-m1.json` is the corrected creator Module 1 script package for AI Essentials for Everyday Work. It contains three concept-topic videos, twenty-one scenes across five teaching stages, six midpoint questions and four module-end questions. Narration is editable teaching prose, not generated audio. Source IDs refer to the saved SME note blocks for course `0cdeff78-e926-4b86-9807-92f6bcbb340b`; objective IDs O1/O2 preserve its module scope.

The package estimates 1,839 narration words at 130 words/minute, 30 seconds of visual transitions and 5.25 minutes of learner activity, within its 20-minute budget. Hook, worked example, guided practice and scenario each use three scenes. Practice attempts pause playback before model feedback. Actual audio duration is measured separately. The reference does not create learner progress, imply independent SME approval or publish the course.
