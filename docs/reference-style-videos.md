# Narrative demonstration video rollout

The creator reviewed the supplied Avyana/ECI video and requested its visual direction for new topic videos and regeneration of existing generated videos. The entire 220-second timeline was inspected locally at two-second intervals, with local narration transcription. No uploaded reference was sent to an external model. This is style inspiration, not evidence for its product or medical claims.

The renderer adds a restrained dark/rose visual identity, a consistent fictional inbox/rule-editor/AI-review workspace for Automation vs AI, and annotated evidence documents for source inspection. These compositions retain source-supported examples and use exact phrase anchors aligned to measured narration. Long read holds remain deliberate; meaningful actions get additional cues. A previously validated storyboard may migrate only when source text, context and audio durations match exactly. New teaching uses normal direction and critique. No claim of a pixel-identical reproduction or a fully automatic recreation of every bespoke reference asset is made.

`hybrid-reference-5` changes derivative cache identity. Existing narration, original recordings, checkpoints, enrollment editions and grades are preserved. Windows status replacement retries transient reader/scanner locks without deleting the current status file. Failed derivatives retain the original-lesson fallback.

From `apps/web`, inventory with `node scripts/regenerate-reference-videos.mjs`; explicitly regenerate prepared lessons with `node scripts/regenerate-reference-videos.mjs --run`. The runner uses the latest adaptation per enrollment/module/piece, resolves the topic against that learner's edition, preserves its text/audio and renders one lesson at a time. Per-asset locks, current renderer keys and a result file in `.data/reference-regeneration-results.json` support reruns without duplicating successful renders. Text/audio jobs that have not completed cannot be counted as regenerated videos; they use the new renderer when they become ready.

The first run freezes its prepared-lesson inventory so retries target the same revisions. To include lessons prepared since that run, use `--run --refresh-inventory`. Historical recordings and older private derivatives are retained.

Verification combines source and checkpoint regressions, native alignment/render reports, complete media decoding, audio waveform comparison, frame inspection and browser playback. Run `scripts/verify-reference-videos.py` with the adaptive-api virtual environment. Record completed/failed counts from the result file rather than treating a queued batch as complete. Local alignment normalizes spelled-out measurements and digit transcriptions, can choose a fully recognized quote within a requested anchor, and can combine adjacent additive layers at their later spoken cue. It never changes narration, invents timestamps, merges incompatible state changes or lowers the source-coverage threshold.
